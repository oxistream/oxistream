# Keyboard shortcuts

Press ++question++ on the watch page for an overlay with these keys. Shortcuts are ignored while typing in a text field.

## Player

| Key | Action |
| --- | --- |
| ++k++ or ++space++ | Play or pause |
| ++j++ / ++l++ | Back / forward 10 seconds |
| ++arrow-left++ / ++arrow-right++ | Back / forward 5 seconds |
| ++0++–++9++ | Jump to 0–90 % |
| ++home++ / ++end++ | Go to start / end |
| ++less++ / ++greater++ | Slower / faster |
| ++shift+p++ / ++shift+n++ | Previous / next video |
| ++arrow-up++ / ++arrow-down++ | Volume up / down |
| ++m++ | Mute |
| ++f++ | Fullscreen |
| ++t++ | Theater mode |
| ++c++ | Captions |
| ++i++ | Picture-in-picture |
| ++question++ | Keyboard shortcuts |
| ++slash++ | Focus search (anywhere) |

"Previous video" restarts the current video if it has played for more than 3 s. Otherwise it goes to the previous playlist video or the video you watched before.

++arrow-up++, ++arrow-down++, ++home++ and ++end++ only work while the player has focus, so the page still scrolls. The mini player only takes ++k++ and ++m++ page-wide.

## Shorts

| Input | Action |
| --- | --- |
| ++arrow-down++ or ++j++, swipe up, scroll | Next short |
| ++arrow-up++ or ++k++, swipe down, scroll | Previous short |
| ++space++, ++m++, ++f++, ++c++, ++0++–++9++ | Same as the video player |
