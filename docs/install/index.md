# Installation

Oxistream is a single container image that needs PostgreSQL 18 or newer.

| Page | Use it for |
| --- | --- |
| [Docker](docker.md) | Running the image yourself, image tags and details, building it |
| [Docker Compose](compose.md) | A single host with PostgreSQL included |
| [Kubernetes](kubernetes.md) | The Helm chart, optionally with CloudNativePG and several replicas |

Afterwards, see [Configuration](../configuration.md) and [Reverse proxy](../reverse-proxy.md).
